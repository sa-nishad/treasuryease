# Naming

## Choice: TreasuryEase

It says the mission in one word (treasury, made easy), reads well in a sentence ("run it through TreasuryEase"), and works as a group name, a site name and a package prefix. Packs sit under it: "a TreasuryEase pack".

- GitHub repository: `sa-nishad/treasuryease` (move it to a `treasuryease` organisation later if the project grows; GitHub redirects the old URL)
- Site: `https://sa-nishad.github.io/treasuryease/`
- Suggested tagline: **Make treasury processing easy.**

## Shortlist

| Name | Strength | Watch out for |
| --- | --- | --- |
| **TreasuryEase** | Says the mission. Easy to spell and say. | "Ease" is common in product names. |
| TreasuryKit | Short. Suggests a toolbox. | Many "kit" projects exist. |
| TreasuryForge | Strong, memorable. | Sounds heavier than small single-purpose packs. |
| Treasury Packs | Describes the model exactly. | Generic, hard to search for. |
| PlainTreasury | Matches the "plain output" principle. | Can read as basic rather than easy. |
| TreasuryBench | Workbench idea. | Suggests a bigger, single application. |

## Before you commit to a name

A quick web search found no obvious product called TreasuryEase, but that is not a trademark search. Before you publish:

1. Search the name in quotes on GitHub, GitLab, PyPI and npm.
2. Check the domain and social handles if you want them.
3. Run a trademark search in the UK and EU for software and financial services.
4. Make sure the repository name is free under your account (it is, unless you already have one called treasuryease).

If any check fails, the second choice is TreasuryKit.
